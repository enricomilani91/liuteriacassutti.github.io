What data this site processes

This site has no login, no account, no shopping cart and no contact form: it does not collect any data through its pages, and it does not set any cookie of its own or from third parties.

The only personal data involved is the technical data that any web server records automatically when a page is requested — IP address, browser type, date and time of the visit — kept in the hosting provider's server logs for the sole purpose of keeping the site secure and working. This site is hosted on GitHub Pages (GitHub, Inc. / GitHub B.V.); see GitHub's Privacy Statement for how that data is handled.

The legal basis for this processing is the legitimate interest (art. 6.1.f GDPR) in operating and securing the site. No profiling and no marketing use is made of this data.
